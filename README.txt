Release 2.6 // Imperial Archive · Lore / Symbol Audit, Class UI and Campaign Stability // 24 October 2026

ЗАПУСК
1. Распакуй архив в отдельную папку, не поверх предыдущей версии.
2. Запусти start_game.bat. Игра запускается через локальный HTTP-сервер на 127.0.0.1; внешняя AI-интеграция не нужна.
3. Если оригинальная папка D:\game\wh40_testvers\assets доступна на этом ПК, импортёр может скопировать оттуда дополнительные графические и аудиоресурсы. Для другого пути используй IMPORT_ASSETS.bat или tools/import-user-assets.ps1 -SourcePath "ПУТЬ\К\assets".
4. Проверь ASSET_IMPORT_REPORT.txt. Текущий архив содержит только реально поставленные файлы; отсутствующие необязательные изображения используют fallback, а не притворяются доступными.
5. В меню доступны начало кампании, введение в Warhammer 40,000 и архив графики/звука. Звуковое сопровождение остаётся необязательным.
6. Для автоматических проверок из корня проекта выполни `node tests/run-qa.cjs`.

RELEASE 2.6
- Исправлена регрессия, из-за которой вступительные бои заменяли исторические точки входа глав и ломали тесты/совместимость.
- В каждой из 15 глав доступен отдельный боевой маршрут с уникальной завязкой, назначенным типом противника и классозависимым текстом. Бой — отдельный выбор, а не принудительная замена исходной сцены.
- После боя игрок возвращается к продолжению исходной сцены. Входные эффекты, проверки и автоматические переходы не выполняются повторно.
- В интерфейсе появились отдельные цветовые акценты Инквизитора, гвардейца и Космодесантника Караула Смерти. Цветовая тема не выдаётся за официальную геральдику.
- Улучшены иерархия панелей, фокус клавиатуры, мобильные отступы и поддержка reduced-motion.
- Составлены аудит символики, матрица лорных ограничений, release notes и отчёт проверки локального запуска.

РЕСУРСЫ И ОГРАНИЧЕНИЯ
- 10 активных файлов изображений присутствуют в поставке; 5 локальных OGG-файлов есть, но звуковое сопровождение необязательно.
- 110 дополнительных графических ресурсов остаются необязательными и не поставляются в бинарном виде в этом архиве. Для использования исходных файлов можно выполнить импортёр на Windows.
- `assets/backgrounds/docks.png` — fallback-копия существующей промышленной панорамы, а не уникальный арт доков.
- Полный интерактивный графический E2E-проход не подтверждён: headless Chromium в сборочной среде зависает до создания надёжного снимка. Не считай это подтверждением отсутствия визуальных дефектов.
- Символы UI являются стилизованными. Точная идентичность всем официальным знакам Games Workshop не заявляется; неподтверждённые символы обозначены как декоративные/авторские.
